# AndAgain AR

**AndAgain AR** - небольшой прототип приложения дополненной реальности, созданный на Unity с использованием AR Foundation. Приложение распознает поверхности через камеру Android-устройства и позволяет размещать стилизованные 3D-растения прямо в реальном окружении.

Основной акцент проекта - простое и наглядное AR-взаимодействие: пользователь касается найденной плоскости, после чего на ней появляется небольшая группа растений. Размещенные объекты можно выбирать и масштабировать жестом двумя пальцами.

## Возможности

* Распознавание поверхностей и raycast через AR Foundation
* Поддержка Android AR через ARCore
* Случайное размещение 3D-prefab'ов растений
* Плавная анимация роста при появлении объектов
* Выбор объекта с визуальной подсветкой
* Масштабирование выбранного объекта pinch-жестом

## Технологии

* Unity 2022.3.24f1
* C#
* AR Foundation 5.1.3
* ARCore XR Plugin 5.1.3
* Android / IL2CPP

## Структура проекта

```text
Assets/
  Scenes/        основная AR-сцена
  Scripts/       логика размещения и взаимодействия с объектами
  Prefabs/       визуализация AR-плоскости
  Materials/     материалы растений и подсветки
  Assets/Models/ 3D-модели растений
Packages/        зависимости Unity
ProjectSettings/ настройки Unity и Android-сборки
```

## Основное взаимодействие

1. Приложение сканирует окружение и находит плоскости.
2. Пользователь касается найденной поверхности.
3. Вокруг точки касания появляется случайная группа растений.
4. Растения плавно увеличиваются от нулевого масштаба до финального размера.
5. Пользователь может выбрать растение и изменить его размер pinch-жестом.
