# My Course Paper

Курсовой проект на C++: консольная модель дискового устройства с папками и файлами.

## Что умеет программа

- создавать новый диск;
- добавлять и удалять папки;
- добавлять файлы в папки;
- искать папки и файлы;
- выводить содержимое диска или отдельной папки;
- сохранять данные в текстовый файл;
- загружать данные из `input.txt`.

## Структура проекта

```text
Source/
├── My_Course_Paper.sln
└── My_Course_Paper/
    ├── main.cpp
    ├── Disk.h
    ├── Folder.h
    ├── File.h
    ├── My_Course_Paper.vcxproj
    ├── My_Course_Paper.vcxproj.filters
    └── *.txt
```

## Основные файлы

- `main.cpp` — меню и обработка команд пользователя.
- `Disk.h` — класс диска и работа со списком папок.
- `Folder.h` — класс папки и работа с файлами.
- `File.h` — класс файла.
- `input.txt` — пример входных данных для чтения.

## Как открыть

1. Откройте `Source/My_Course_Paper.sln` в Visual Studio.
2. Выберите конфигурацию `Debug` или `Release`.
3. Запустите проект.

## Временные файлы

Папки `.vs`, `x64`, `Debug`, а также файлы `.obj`, `.pdb`, `.ilk`, `.tlog` являются результатами сборки Visual Studio. Они не нужны для чтения исходного кода и могут быть созданы заново при следующей сборке проекта.
