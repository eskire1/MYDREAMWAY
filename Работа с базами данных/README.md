# Портфолио работ по базам данных

Репозиторий содержит SQL-скрипты для Microsoft SQL Server. Работы охватывают проектирование реляционных баз данных, базовые операции SQL, возможности Transact-SQL и примеры для распределённых информационных систем.

## Структура проекта

```text
01-Основы SQL/
  книжный-магазин-авторы-книги-ограничения.sql
  дропшиппинг-схема-базы-и-тестовые-данные.sql
  магазин-отделы-соединения-и-скидки.sql
  магазин-товары-crud-и-агрегация.sql

02-Возможности Transact-SQL/
  01-выгрузка-данных-в-xml.sql
  02-разбор-xml-метаданных-товара-openxml.sql
  03-xquery-и-методы-xml.sql
  04-анализ-индексов-и-оптимизация-запросов.sql
  05-представления-check-option-и-индексированные-представления.sql
  06-dml-триггеры.sql
  07-хранимые-процедуры-и-функции.sql

03-Распределенные информационные системы/
  01-Разделение товаров и продаж/
    база-товаров-схема-и-тестовые-данные.sql

  02-Межбазовые запросы и операции/
```

## Содержание

- `01-Основы SQL` — создание баз данных и таблиц, первичные и внешние ключи, ограничения, заполнение таблиц, CRUD-операции, соединения, группировка, агрегатные функции и расчёт скидок.
- `Операции с базами данных` — отдельные сценарии для книжной базы авторов и книг, товарного учета, CRUD-операций, фильтрации, агрегатных расчетов, соединений таблиц, скидок и внешних ключей.
- `02-Возможности Transact-SQL` — выгрузка данных в XML, разбор XML через `OPENXML`, методы XQuery, анализ индексов, оптимизация запросов, представления, индексированные представления, DML-триггеры, хранимые процедуры и пользовательские функции.
- `03-Распределенные информационные системы` — разделение предметной области на несколько баз данных, межбазовые запросы, операции изменения данных, торговая база, связанный сервер, процедуры, управление правами и хранение состояния.

## Примечания

Скрипты предназначены для демонстрации навыков работы с Microsoft SQL Server / SQL Server Management Studio. Перед запуском рекомендуется просматривать каждый файл отдельно: некоторые работы содержат команды `DROP DATABASE`, `DELETE` и тестовые `UPDATE`.
