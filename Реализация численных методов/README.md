# Реализация численных методов

Небольшая коллекция программ на Python, посвященная классическим численным методам из курса высшей математики. Каждый файл содержит отдельную лабораторную работу или самостоятельную реализацию метода: от решения нелинейных уравнений до разностных схем для дифференциальных уравнений.

## Содержание

| Файл | Что реализовано |
| --- | --- |
| `Методы простых итераций Зейделя и релаксации для СЛАУ.py` | Решение системы линейных алгебраических уравнений методами простых итераций, Зейделя и релаксации |
| `Методы простых итераций и Ньютона для нелинейного уравнения.py` | Поиск корня нелинейного уравнения методами простых итераций, Ньютона и модифицированного Ньютона |
| `Методы простых итераций и Ньютона для системы нелинейных уравнений.py` | Решение системы нелинейных уравнений итерационными методами |
| `Интерполяция Ньютона и Лагранжа численное дифференцирование.py` | Интерполяционные многочлены Ньютона и Лагранжа, численное дифференцирование |
| `Численное интегрирование методами трапеций Симпсона и Гаусса.py` | Приближенное вычисление определенного интеграла методами трапеций, Симпсона и Гаусса |
| `Численное интегрирование методами трапеций Симпсона и Гаусса remake.py` | Альтернативная версия программы для численного интегрирования |
| `Двойное интегрирование методом Симпсона.py` | Численное вычисление двойного интеграла по составной формуле Симпсона |
| `Решение задачи Коши методами Эйлера Рунге-Кутты и Адамса.py` | Решение задачи Коши для ОДУ методами Эйлера, Рунге-Кутты и Адамса |
| `Метод прогонки для краевой задачи.py` | Решение краевой задачи методом прогонки для трехдиагональной системы |
| `Явная разностная схема для гиперболического уравнения.py` | Явная разностная схема для уравнения гиперболического типа |
| `Явная и неявная разностные схемы для параболического уравнения.py` | Явная и неявная схемы для уравнения параболического типа |
| `Метод Леверрье для характеристического многочлена и обратной матрицы.py` | Метод Леверрье для построения характеристического многочлена и нахождения обратной матрицы |

## Запуск

Для работы нужен Python 3 и библиотеки, используемые в отдельных программах:

```bash
pip install numpy prettytable
```

Запуск любого файла:

```bash
python "Название файла.py"
```

Некоторые программы запрашивают начальные приближения, количество разбиений или параметр схемы через консоль.

## О проекте

Проект удобно использовать как набор учебных примеров: код показывает не только итоговое значение, но и промежуточные итерации в табличном виде. Это помогает сравнивать скорость сходимости методов, оценивать погрешность и видеть, как меняется решение на каждом шаге.
