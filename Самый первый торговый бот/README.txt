Программа написана на языке Python. Сама программа представляет собой торгового бота, работающего с биржей BingX и совершающего торговые операции с криптовалютой.

За основу бота взят алгоритм, который был представлен Trading View - популярной веб-платформой для анализа финансовых рынков. Сам алгоритм работает в цикле и напоминает скрипт. Изначально алгоритм и создавался его имитирующим, так было проще реализовать логику работы алгоритма.

Бот работает на половину успешно, его работе мешает неопределённость сигнала в момент его появления.
