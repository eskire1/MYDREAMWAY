# Портфолио по компьютерной графике

Эта папка содержит три выбранные работы по OpenGL, подготовленные для портфолио при поступлении в вуз. Я оставил только показательные исходники, шейдеры, модели, текстуры и вспомогательный код, без временных файлов сборки.

## 01. Система частиц

**Папка:** `Система частиц`

Интерактивная система частиц на OpenGL 3.3. Частицы создаются, обновляются, сортируются по расстоянию до камеры и выводятся как billboard-спрайты с текстурой.

Что показывает работа:

- использование GLEW, GLFW и GLM;
- генерацию и обновление большого числа частиц;
- работу с VBO и instancing;
- использование вершинного и фрагментного шейдера;
- базовую камеру и управление сценой.

Ключевые файлы:

- `основной_код_системы_частиц.cpp`
- `вершинный_шейдер_частиц.vertexshader`
- `фрагментный_шейдер_частиц.fragmentshader`
- `текстура_частиц.DDS`

## 02. Карта теней

**Папка:** `Карта теней`

Проект с реализацией shadow mapping: сцена сначала рендерится с позиции источника света в карту глубины, затем эта карта используется при основном рендеринге для определения затененных участков.

Что показывает работа:

- понимание 3D-камеры, матриц модели, вида и проекции;
- загрузку OBJ-модели;
- рендеринг в framebuffer;
- создание depth texture;
- использование GLSL-шейдеров для расчета теней;
- работу с текстурами и буферами вершин.

Ключевые файлы:

- `основной_код_карты_теней.cpp`
- `вершинный_шейдер_теней.vertexshader`
- `фрагментный_шейдер_теней.fragmentshader`
- `вершинный_шейдер_глубины.vertexshader`
- `фрагментный_шейдер_глубины.fragmentshader`
- `модель_для_демонстрации_теней.obj`
- `текстура_модели.DDS`

## 03. Текстурированная 3D-модель

**Папка:** `Текстурированная 3D модель`

Учебная 3D-сцена с текстурированной объемной моделью, материалами, источником света и переключением режимов отображения.

Что показывает работа:

- построение 3D-геометрии вручную;
- назначение нормалей поверхностям;
- загрузку BMP-текстур;
- работу с материалами и освещением;
- применение display lists;
- управление вращением и режимом отсечения граней.

Ключевые файлы:

- `основной_код_текстурированной_модели.cpp`
- `текстура_левая_грань.bmp`
- `текстура_нижняя_грань.bmp`
- `текстура_верхняя_и_задняя_грани.bmp`
- `библиотека_загрузки_BMP.h`
- `библиотека_загрузки_BMP.lib`
