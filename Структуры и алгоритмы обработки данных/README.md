# Project2

Учебный C++ проект с программами по структурам данных и алгоритмам обработки данных.

## Что внутри

Проект собран как набор лабораторных и экспериментальных решений для Visual Studio. В файлах встречаются реализации и заготовки по следующим темам:

- линейные списки, списки списков и работа с указателями;
- стек, очередь и вспомогательные структуры;
- бинарные деревья поиска, обходы, поиск и удаление узлов;
- сортировки: пузырьковая, выбором, Шелла, быстрая сортировка;
- хеш-таблицы с разрешением коллизий цепочками;
- небольшие эксперименты со строками, памятью, `sizeof`, `typeinfo` и случайными числами.

## Основные файлы

| Файл | Назначение |
| --- | --- |
| `SDPA_t4_ex3.cpp` | Активная программа: список списков с меню, добавлением, поиском, выводом и удалением элементов. |
| `List_of_lists_and_related_functions.cpp` | Более расширенная версия списка списков и связанных функций. |
| `SDPA_t5_*.cpp`, `SDPA_t6_ex1.cpp` | Бинарные деревья поиска и операции над ними. |
| `SDPA2_t2_*.cpp`, `SDPA2_t3.cpp` | Алгоритмы сортировки и сравнение их работы. |
| `SDPA2_t4_*.cpp` | Хеш-таблицы и тестирование хеширования. |
| `Try_*.cpp` | Черновики и небольшие эксперименты с языком C++. |

## Как открыть

1. Откройте `Project2.vcxproj` в Visual Studio.
2. Выберите конфигурацию `Debug` и платформу `x64`.
3. Соберите и запустите проект.

## Примечания

- Большая часть файлов сейчас хранит код в закомментированном виде. Это удобно как архив решений, но для запуска конкретной лабораторной нужно оставить активным только один `main`.
- В текущем состоянии обычный `int main()` находится в `SDPA_t4_ex3.cpp`.
- Если русский текст в консоли отображается некорректно, проверьте кодировку исходников и настройки консоли Windows.
