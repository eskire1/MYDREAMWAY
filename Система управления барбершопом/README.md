# Barbershop

Сайт барбершопа с онлайн-записью и простой админ-панелью для управления услугами, сотрудниками, клиентами и расписанием.

## Возможности

- просмотр услуг и информации о барбершопе;
- отправка сообщений через контактную форму;
- онлайн-бронирование с выбором услуги, сотрудника, даты и времени;
- админ-панель для управления категориями, услугами, сотрудниками и записями;
- настройка рабочего расписания сотрудников.

## Стек

- PHP
- MySQL / MariaDB
- HTML, CSS, Bootstrap
- JavaScript, jQuery, Ajax

## Установка

1. Скопируйте проект в папку локального сервера, например `htdocs` для XAMPP.
2. Создайте базу данных `barbershop`.
3. Импортируйте файл `barbershop_db.sql`.
4. Проверьте настройки подключения в `connect.php` и `barber-admin/connect.php`.
5. Откройте сайт в браузере.

## Админ-панель

Адрес:

```text
http://localhost/barbershop-website-php-mysql-main/barber-admin/
```

Демо-доступ:

```text
Логин: admin
Пароль: 123456789
```

## Структура

- `index.php` - главная страница;
- `appointment.php` - форма записи;
- `calendar.php` - генерация доступных слотов;
- `barber-admin/` - административная часть;
- `Design/` - стили, скрипты, изображения и шрифты;
- `Includes/` - шаблоны, функции и Ajax-обработчики;
- `barbershop_db.sql` - дамп базы данных.

## Примечание

Проект рассчитан на локальный запуск и учебную доработку. Перед публикацией рекомендуется усилить безопасность: обновить хранение паролей, закрыть Ajax-действия проверкой авторизации и вынести параметры базы данных из кода.
